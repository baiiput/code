Reset Data System

Halaman Admin - Gunakan dengan Hati-hati

⚠️ PERINGATAN PENTING!

Tindakan ini akan menghapus SEMUA data testing dan tidak dapat di-undo!

Pastikan Anda sudah melakukan backup database sebelum melanjutkan.

📦 Sudah Backup Database?

Jangan lupa export database dulu sebelum reset!

📋 Data yang Akan Di-reset:

  • Semua transaksi stock IN (pembelian dari supplier)
  • Semua transaksi stock OUT (distribusi ke cabang)
  • History penyesuaian stok
  • Data transaksi keuangan
  • Stok item (reset ke 0)
  • Saldo warehouse (reset ke 0)

Yang TIDAK dihapus: Data master items, suppliers, branches, categories, dan users

🔧 Cara 1: Reset via phpMyAdmin (Recommended)

Langkah 1: Login ke phpMyAdmin
Langkah 2: Pilih database warehouse Anda
Langkah 3: Klik tab "SQL" di bagian atas
Langkah 4: Copy-paste query SQL di bawah ini:
-- Reset Semua Data Transaksi dan Keuangan -- BACKUP DATABASE DULU SEBELUM JALANKAN INI! -- 1. Hapus semua transaksi stock OUT (distribusi ke cabang) TRUNCATE TABLE stock_out_detail; TRUNCATE TABLE stock_out; -- 2. Hapus semua transaksi stock IN (pembelian dari supplier) TRUNCATE TABLE stock_in_detail; TRUNCATE TABLE stock_in; -- 3. Hapus semua penyesuaian stok TRUNCATE TABLE stock_adjustment; -- 4. Hapus semua history transaksi keuangan TRUNCATE TABLE financial_transactions; -- 5. Reset stok semua item ke 0 UPDATE items SET current_stock = 0, average_cost = 0; -- 6. Reset saldo warehouse ke 0 UPDATE warehouse_balance SET balance_amount = 0 WHERE balance_id = 1; -- 7. (Opsional) Reset data cabang - Hapus -- di bawah jika mau reset -- TRUNCATE TABLE branches; -- 8. (Opsional) Reset data supplier - Hapus -- di bawah jika mau reset -- TRUNCATE TABLE suppliers; -- Selesai! Database siap untuk data real
Langkah 5: Klik tombol "Go" atau "Jalankan" untuk eksekusi query
Langkah 6: Refresh halaman sistem Anda dan cek hasilnya

🔧 Cara 2: Reset Selective (Per Bagian)

Jika hanya ingin reset bagian tertentu, gunakan query individual:

Reset Transaksi Saja:

TRUNCATE TABLE stock_out_detail; TRUNCATE TABLE stock_out; TRUNCATE TABLE stock_in_detail; TRUNCATE TABLE stock_in; TRUNCATE TABLE stock_adjustment; UPDATE items SET current_stock = 0, average_cost = 0;

Reset Keuangan Saja:

TRUNCATE TABLE financial_transactions; UPDATE warehouse_balance SET balance_amount = 0 WHERE balance_id = 1;

Reset Master Data (Cabang & Supplier):

TRUNCATE TABLE branches; TRUNCATE TABLE suppliers;

✅ Checklist Sebelum Reset:

💡 Tips Setelah Reset:

  • Mulai input data master dulu (produk, cabang, customer)
  • Lalu input stok awal gudang
  • Baru input transaksi dari tanggal mulai operasional
  • Set saldo awal keuangan sesuai kondisi real
  • Test sistem dengan beberapa transaksi untuk memastikan
