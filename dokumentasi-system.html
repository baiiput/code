📊 Overview System

System Warehouse ini adalah aplikasi manajemen gudang lengkap untuk bisnis distribusi dimsum yang mencakup:

📦 Manajemen Stok

Tracking stok gudang real-time dengan history lengkap

🏪 Multi-Cabang

Kelola distribusi ke berbagai cabang penjualan

💰 Keuangan

Tracking pembayaran, hutang, dan saldo keuangan

📈 Laporan

Dashboard dan laporan lengkap untuk analisa bisnis

🚀 Setup Awal System

Langkah-langkah Setup:

  1. Setup Database
    Import file database.sql ke MySQL/phpMyAdmin Anda. Pastikan semua tabel ter-create dengan baik.
  2. Konfigurasi Koneksi
    Edit file config.php dan sesuaikan parameter database:
    $db_host = "localhost"; $db_user = "root"; $db_pass = ""; $db_name = "warehouse_db";
  3. Test Koneksi
    Buka halaman index.html di browser dan pastikan tidak ada error koneksi.
  4. Login Pertama Kali
    Username: admin, Password: admin (segera ganti password!)

🔄 Reset Data Testing

⚠️ PERINGATAN!
Reset data akan menghapus SEMUA transaksi dan data keuangan. Pastikan sudah backup dulu!

Kapan Perlu Reset Data?

  • Setelah selesai testing dan mau mulai pakai data real
  • Setelah training team dan mau mulai operasional
  • Ketika ada data testing yang salah dan mau dibuang semua

Cara Reset Data via phpMyAdmin:

  1. Login phpMyAdmin
    Akses phpMyAdmin via browser (biasanya http://localhost/phpmyadmin)
  2. Pilih Database
    Klik database warehouse Anda di sidebar kiri
  3. Buka Tab SQL
    Klik tab "SQL" di bagian atas halaman
  4. Jalankan Query Reset
    Copy-paste query ini:
    -- BACKUP DULU SEBELUM JALANKAN! -- Hapus semua transaksi DELETE FROM stock_out_detail; DELETE FROM stock_out; DELETE FROM stock_in_detail; DELETE FROM stock_in; DELETE FROM stock_adjustment; DELETE FROM financial_transactions; -- Reset AUTO_INCREMENT ALTER TABLE stock_out AUTO_INCREMENT = 1; ALTER TABLE stock_in AUTO_INCREMENT = 1; -- Reset stok ke 0 UPDATE items SET current_stock = 0, average_cost = 0; -- Reset saldo warehouse ke 0 UPDATE warehouse_balance SET balance_amount = 0 WHERE balance_id = 1; -- Opsional: Reset master data -- DELETE FROM branches; -- DELETE FROM suppliers;
  5. Klik "Go"
    Klik tombol "Go" atau "Jalankan" untuk eksekusi query
  6. Refresh System
    Refresh halaman warehouse system dan cek hasilnya
💡 Akses Halaman Reset:
Untuk panduan lengkap dan checklist, buka: admin-reset-data.html

📝 Input Data Real (Setelah Reset)

Urutan Input Data yang Benar:

  1. Data Master Produk
    Input/cek semua produk dimsum yang dijual. Pastikan nama, harga, dan satuan sudah benar.
  2. Data Cabang
    Input semua cabang penjualan dengan data lengkap (nama, alamat, kontak).
  3. Data Customer/Pelanggan
    Input data pelanggan tetap jika ada.
  4. Stok Awal Gudang
    Input stok awal yang ada di gudang saat mulai pakai system (via transaksi masuk atau langsung edit stok).
  5. Saldo Awal Keuangan
    Set saldo awal keuangan sesuai kondisi real bisnis.
  6. Mulai Transaksi Normal
    Mulai input transaksi harian (masuk/keluar barang) dari sekarang.
✅ Tips Penting:
  • Tentukan tanggal cutoff yang jelas untuk mulai pakai system
  • Lakukan stock opname fisik sebelum input stok awal
  • Dokumentasikan saldo awal dan stock awal untuk audit

📦 Transaksi Harian

Transaksi Masuk Barang:

Digunakan saat ada barang masuk ke gudang (dari supplier/produksi).

  • Pilih produk dan quantity
  • Input harga beli (untuk perhitungan margin)
  • Stok gudang akan otomatis bertambah
  • History tercatat lengkap

Transaksi Keluar Barang:

Digunakan saat distribusi ke cabang atau penjualan langsung.

  • Pilih cabang tujuan
  • Pilih produk dan quantity
  • Input harga jual dan status pembayaran
  • Stok gudang akan otomatis berkurang
  • Jika belum lunas, tercatat sebagai piutang
💡 Tips Transaksi:
Selalu cek stok gudang sebelum input transaksi keluar untuk menghindari stok negatif!

💾 Backup Database

⚠️ PENTING!
Lakukan backup database secara rutin (minimal seminggu sekali atau sebelum reset data)!

Cara Backup via phpMyAdmin:

  1. Login phpMyAdmin
    Akses phpMyAdmin di browser
  2. Pilih Database
    Klik database warehouse di sidebar kiri
  3. Klik Tab "Export"
    Klik tab "Export" di bagian atas
  4. Pilih "Quick" Method
    Pilih metode "Quick" dan format "SQL"
  5. Klik "Go"
    File .sql akan terdownload. Simpan dengan nama yang jelas (misal: warehouse_backup_2024-11-14.sql)

Cara Restore Backup:

  1. Login phpMyAdmin
  2. Pilih database warehouse
  3. Klik tab "Import"
  4. Pilih file backup .sql
  5. Klik "Go" untuk restore

🔧 Troubleshooting

Problem: Stok Negatif

Penyebab: Transaksi keluar melebihi stok yang ada

Solusi: Cek history transaksi dan lakukan penyesuaian stok manual atau batalkan transaksi yang salah

Problem: Data Tidak Muncul

Penyebab: Error koneksi database atau query

Solusi: Cek console browser (F12) untuk error, pastikan koneksi database OK

Problem: Saldo Keuangan Tidak Cocok

Penyebab: Ada transaksi yang belum tercatat pembayarannya

Solusi: Cek laporan piutang dan update status pembayaran yang seharusnya sudah lunas

Problem: Lupa Password Admin

Solusi: Reset via phpMyAdmin dengan query:

UPDATE users SET password = MD5('admin123') WHERE username = 'admin';

💡 Tips & Best Practice

Daily Operations:

  • Input transaksi sesegera mungkin setelah terjadi
  • Cek dashboard setiap pagi untuk overview bisnis
  • Update status pembayaran begitu pelunasan diterima
  • Lakukan stock opname fisik minimal sebulan sekali

Data Management:

  • Backup database setiap minggu atau sebelum action penting
  • Export laporan keuangan untuk arsip bulanan
  • Jangan hapus data transaksi sembarangan
  • Gunakan fitur filter dan pencarian untuk efisiensi

Security:

  • Ganti password default admin segera
  • Jangan share password ke sembarang orang
  • Logout setelah selesai menggunakan system
  • Batasi akses phpMyAdmin hanya untuk admin IT
